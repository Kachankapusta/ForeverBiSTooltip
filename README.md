# Forever BiS Tooltip

Browse best-in-slot gear, enchants, and gems for **World of Warcraft: Forever**. Compare alternatives, check item sources, and build a shopping list for the materials you still need.

## Features

- **Gear browser.** Filter recommendations by class, specialization, and phase. The bundled lists cover Pre-Raid and offer a Realistic variant where available. Resize the window to fit more alternatives in each row.
- **BiS ranks in item tooltips.** See ranks grouped by class and specialization, with icons and an equipped or in-bags status when applicable. Show all ranks or limit the display to Top 1, Top 3, or Top 5. You can also filter to the selected specialization or show recommendations only while holding Ctrl.
- **Enchants and gems.** See effects, crafting materials, and quest exchange requirements when available.
- **Per-character Shopping List.** Check owned and required quantities using bag and bank counts, including bound materials and gold needed for exchanges. Use the plus and minus buttons to change how many sets you need. Hover over an item or spell link to see its game tooltip at the cursor.
- **Optional Auctionator integration.** Sync missing materials that can be bought at the auction house to the **Forever BiS Shopping** list in Auctionator.

## Getting started

Download the latest addon from [CurseForge](https://www.curseforge.com/wow/addons/forever-bis-tooltip) or [GitHub Releases](https://github.com/Kachankapusta/ForeverBiSTooltip/releases/latest/download/ForeverBiSTooltip.zip).

Extract the ZIP so that the `ForeverBiSTooltip` folder is inside `Interface/AddOns`. Toggle the gear browser with `/fbt`, `/bistooltip`, or a left-click on the cabbage minimap button.

## Controls

| Where | Action | Result |
| --- | --- | --- |
| Enchant or gem in the gear browser | Left-click | Add one set of materials when available |
| Enchant or gem in the gear browser | Right-click | Remove one set from the Shopping List |
| Enchant or gem in the gear browser | Shift + left-click | Inspect the enchant, recipe, or item |
| **Shopping** in the gear browser or cabbage tab at the auction house | Left-click | Open or close the Shopping List |
| **Shopping** in the gear browser | Right-click | Restore the default size and dock the Shopping List to the gear browser |
| Cabbage minimap button | Right-click | Open or close the same Shopping List, even when the gear browser is closed |
| Cabbage minimap button | Shift + left-click | Open addon settings |

When opened from the gear browser or minimap, drag the Shopping List by its title bar to position it separately or use its bottom-right corner to resize it.

Open settings with the gear icon in the browser or under **Options → AddOns → Forever BiS Tooltip**. Choose whether the Shopping List opens automatically when you add an enchant or gem, closes with the gear browser, or shows only missing reagents. You can also reset the gear browser and Shopping List layouts from settings.
