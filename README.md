# Forever BiS Tooltip

Browse best-in-slot gear recommendations and compare alternatives for **World of Warcraft: Forever**. See where items come from, which specializations use them, and what you need for enchants and gems.

## Features

- **Gear browser** with class, specialization, and phase filters. Switch to Realistic when the selected list offers it. Resize the window to fit more items per row.
- **BiS ranks in item tooltips** organized by class and specialization. The tooltip also shows whether the character has the item equipped or in their bags.
- **Enchant and gem recommendations** with effects, crafting materials, and quest requirements when available.
- **Shopping lists saved per character** that use bag and bank counts to calculate what is missing. The panel also tracks bound materials and gold needed for quest exchanges.
- **Optional Auctionator integration** that sends missing purchasable materials to the **Forever BiS Shopping** list. Open the Shopping panel from the gear window or the cabbage tab at the auction house.

## Getting started

Place the `ForeverBiSTooltip` folder in `Interface/AddOns`, then open the gear browser with `/fbt`, `/bistooltip`, or the minimap button. Use the gear icon in the browser to open the addon's settings.

| Click an enchant or gem | What it does |
| --- | --- |
| Left-click | Add one set of materials to Shopping |
| Right-click | Remove one set from Shopping |
| Shift + left-click | Inspect the enchant, recipe, or item |
